# Natalia

Build a complete, ultra-premium Greek nail salon demo website called "Lumière Nails" in Athens. This must look like it was designed by a world-class agency. Every section must feel luxurious, feminine and expensive. No generic layouts. Every detail matters.

COLORS:

Primary: Soft blush pink (#F2C4CE)

Secondary: Rose gold (#B76E79)

Dark: Deep black (#080808)

Light: Pearl white (#FAFAFA)

Accent: Gold (#D4AF37)

FONTS:

Import from Google Fonts: "Cormorant Garamond" for ALL headings (elegant, luxury, fashion magazine feel)

"DM Sans" for ALL body text (clean, modern, readable)

Apply these fonts globally throughout entire website

GLOBAL DESIGN RULES:

Import Cormorant Garamond + DM Sans from Google Fonts

Every section has generous padding (80-120px top/bottom)

Lots of white space — never cramped

Rose gold (#B76E79) as primary accent everywhere

All cards: subtle box shadow, rounded corners (12-16px)

All buttons: rounded pill shape, no sharp corners

All hover effects: translateY(-6px to -8px) + deeper shadow

Scrolling marquee text in Section 2

Mobile fully responsive — all grids stack to 1 column

Smooth scroll behavior
